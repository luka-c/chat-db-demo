# Chat Demo API

### Developed with

- Deno
- Hono
- SQLite

<br />

## How to run the program

Run the program with all permissions

```
deno task start
```

<br />

Run the program with all permissions and make it reset on changes

```
deno task dev
```

<br />

Run all tests (files with .test in their name)

```
deno task test
```

(The database is created in memory for tests)
